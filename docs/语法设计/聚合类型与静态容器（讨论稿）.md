# 聚合类型与静态容器（讨论稿）

> 状态：表面语法与静态 lowering 已实现；定长 Array 在标准计数循环中的受证明动态下标已接入物理 Memory runtime。动态长度、嵌套聚合和可变 List/Set 仍未实现。

## 目标

MPL 不把 mlog 的单个变量伪装成任意对象。第一版元组、数组、List 和 Set 都是**编译期已知长度**的聚合值：编译器为每一个元素分配私有处理器变量槽，并在构建期检查下标和资源消耗。

这使常见的常量配置、坐标、有限任务表和只读成员表可直接编译，同时不会在尚未完成 Memory runtime 时承诺错误的动态行为。

## 类型与字面量

### 元组

元组是定长、可异构、按位置访问的值。类型和值都使用圆括号，至少有两个元素：

~~~mpl
val test: (Int, Int, Int) = (1, 2, 3);
val spawn: (Float, Float, Bool) = (24.0, 48.0, true);

val x: Int = spawn[0];
val enabled: Bool = spawn[2];
~~~

元组没有单元素形式，`(value)` 始终只是分组表达式。元组元素不可修改，元组也不能整体重新赋值。

### 数组

数组是元素类型一致、定长的可索引序列。数组长度不写入类型，而由初始化字面量确定：

~~~mpl
val array: Int[] = [1, 2, 3, 4, 5];
var path: Float[] = [16.0, 32.0, 48.0];
val inferred = [1, 2, 3];       // 推导为 Int[]
val mixed = [1, 2.5];           // 推导为 Float[]
~~~

空数组没有元素可用于推导，必须有类型标注：

~~~mpl
val empty: Int[] = [];
~~~

`var` 数组可使用 `set` 修改已有元素，`val` 数组不允许修改：

~~~mpl
var queue: Int[] = [10, 20, 30];
queue.set(1, 25);
~~~

`set` 的下标可以是编译期已知且不越界的非负 `Int` 字面量，也可以是下述标准计数循环中被证明安全的下标。数组不能增删元素，也不能整体复制或重新赋值；动态长度属于后续 `MutableList` 设计。

~~~mpl
for (var i: Int = 0; i < queue.size; i += 1) {
    queue.set(i, queue[i] + 1);
}
~~~

### List 与 Set

`List<T>` 是有序只读序列；`Set<T>` 是无序只读成员集合。两者使用工厂创建：

~~~mpl
val targets: List<Int> = listOf(4, 8, 15, 16);
val aliases = List.of("north", "east");

val allowed: Set<Int> = setOf(1, 3, 5);
val priorities = Set.of(10, 20, 30);
~~~

有元素时，`T` 由元素推导；空集合需要目标类型：

~~~mpl
val noTargets: List<Int> = List.of();
val noIds: Set<Int> = setOf();
~~~

当前 `Set` 只接受互不重复的静态字面量。这保证 Set 真的具有去重语义，而不是在没有动态 Memory runtime 时降级为数组。`List` 和 `Set` 都不可修改，也不能整体复制或重新赋值。

## 通用访问与遍历

元组、数组、List、Set 都支持常量下标读取和 `size`：

~~~mpl
val point: (Int, Int) = (12, 34);
val values: Int[] = [3, 6, 9];
val items = listOf(7, 8, 9);

val y: Int = point[1];
val first: Int = values.get(0);
val count: Int = items.size;
~~~

数组、List、Set 还支持成员测试：

~~~mpl
if (values.contains(6)) {
    // ...
}
~~~

集合长度和下标均在编译期证明。动态下标当前仅用于元素为 `Int`、`Float` 或 `Bool` 的具名 Array，且只接受 `for (var i = 0; i < array.size; i += 1)` 证明形式。List、Set、元组的运行时下标、取元素失败返回 `null`、切片和迭代器对象尚未启用；越界或无法证明的下标会报告 `MPL3601`，不会生成可能错误的 mlog。

所有同构元组、数组、List、Set 可用于 `for`：

~~~mpl
var total: Int = 0;
for (var value : values) {
    if (value == 6) {
        continue;
    }
    total += value;
    if (total > 10) {
        break;
    }
}
~~~

异构元组没有统一元素类型，不能直接 `for`，但仍可按常量下标读取。`break` 和 `continue` 遵守普通循环语义，分别跳出整个遍历和进入下一个静态元素。

## 当前限制与后续演进

- 容器元素不能是元组、数组、List 或 Set；嵌套布局需要 Memory runtime。
- 不能把聚合值作为函数参数或返回值；当前静态函数 ABI 只支持标量。
- `List` 与 `Set` 尚无 `add`、`remove`、`clear`；未来将以容量证明和自动内存布局引入 `MutableList<T>`、`MutableSet<T>`。
- 字符串元素可声明和遍历，但动态字符串运行时仍受字符串表设计约束。
- Unit/Building 查询是游戏对象的惰性查询，不是这里的静态 `List`；它们的 API 和弱一致性规则见《单位遍历与私有运行时（讨论稿）》。

这组限制都是构建期失败，不提供运行时异常或隐式降级。构建报告应在后续版本记录每个静态聚合占用的私有变量槽和由此带来的指令数。

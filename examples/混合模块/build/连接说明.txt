MPL 外部硬件连接说明
蓝图：MPL-mixed-modules-0.1.0-c60b68eb7d46
构建：c60b68eb7d46c42e29a5a1bce4aace6ec7510fb3e787bb8f393a8c4925b77e92

所有外部硬件只连接 Main。Main 是蓝图最左侧处理器，局部坐标为 (1, 1)。
打开处理器代码时，首行应为：# MPL shard: Main / build: c60b68eb7d46

按以下 alias 连接；多个同类建筑按数字从小到大连接：
- Status : Message -> message1

选中 Main 进入配置模式后，游戏会在已连接建筑上显示实际 alias；必须与上表一致。
Main 会等待全部 alias 存在且类型正确后再进入顶层程序；连接完成后无需重新写入代码。
